# v0.1.9（2026-06-30）

变更概述

- 新增：媒体名字刮削功能，支持复用已配置的 OpenList 引擎，浏览 OpenList 目录，按电影/电视剧类型预览命名结果，并后台执行文件与根目录重命名。对应代码：frontend/src/views/page/mediaScraping/index.vue、controller/mediaScrapingController.py、service/mediaScraping/mediaScrapingService.py、media_tools/openlist_media_renamer.py
- 新增：引擎管理中增加“刮削配置”，统一配置默认 OpenList 引擎、TMDb API Key/Bearer Token、语言、媒体扩展名、电影/电视剧命名模板、自定义词、制作组、自定义标签、改名线程数、OpenList/TMDb 超时和重命名日志保留数量。对应代码：frontend/src/views/page/engine/index.vue、frontend/src/api/mediaScraping.js、service/mediaScraping/mediaScrapingService.py
- 新增：TMDb 名称搜索，支持在 TMDb ID 输入框右侧打开搜索层，按电影或电视剧名称搜索，展示缩略图、类型、年份、简介和 ID，选中后自动回填 TMDb ID 并切换媒体类型。对应代码：frontend/src/views/page/mediaScraping/index.vue、service/mediaScraping/mediaScrapingService.py
- 新增：媒体刮削任务与执行日志，按媒体目录归档多次执行记录，支持查看任务进度、详情、明细、终止任务、手动执行历史任务，并按配置保留最近若干个重命名任务。对应代码：frontend/src/views/page/mediaScraping/taskDetail.vue、frontend/src/views/page/mediaScraping/taskItemDetail.vue、mapper/mediaScrapingMapper.py、common/sqlInit.py
- 优化：重命名执行顺序改为先处理文件和季目录，再最后重命名根目录；使用预览结果执行时不重复查询 TMDb，降低应用命名耗时。对应代码：service/mediaScraping/mediaScrapingService.py、media_tools/openlist_media_renamer.py
- 优化：手动执行历史任务时强制刷新源/目标根目录及其父目录，根目录重命名前也刷新父目录，减少 OpenList 缓存导致的路径误判。对应代码：service/mediaScraping/mediaScrapingService.py、media_tools/openlist_media_renamer.py
- 调整：左侧菜单新增“媒体名字刮削”，位于“作业管理”与“全局排除项”之间；前端路由新增媒体刮削首页、任务详情和任务明细页。对应代码：frontend/src/views/layout.vue、frontend/src/router/index.js
- 文档：更新 README 的功能说明、使用流程、接口概览和项目目录树。

注意事项

- 媒体名字刮削依赖 TMDb 配置；未配置 TMDb API Key 或 Bearer Token 时，启用“必须配置 TMDb”会阻止预览和搜索。
- 当前重命名默认保护已有目标路径；如果目标目录真实存在，根目录重命名仍会失败，需要后续根据使用场景决定覆盖、合并或自动加后缀策略。
- 本版本只更新源码功能与文档；发布 Docker 或静态前端仍需按发布流程重新构建前端产物。
