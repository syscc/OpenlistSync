# v0.3.1（2026-08-01）

变更概述

- 界面：统一使用 Lucide 图标，重构登录页、应用框架、作业管理、媒体名字刮削、引擎管理、通知渠道和详情页面，并补充明暗主题、响应式布局和减少动态效果支持。
- 导航：一级导航聚焦作业管理、媒体名字刮削、引擎管理和系统设置；全局排除与通知渠道迁入系统设置，桌面端使用横向二级菜单，窄屏使用下拉选择，并兼容旧路由跳转。
- 作业：在作业详情返回按钮旁增加手动执行按钮，桌面端与移动端共用现有手动执行接口。
- 媒体刮削：工作台上下区域按 `3:2` 分配空间，优化目录浏览、命名预览、重命名任务、TMDb 搜索和任务详情的可访问性与移动端交互。
- TMDb：新增 API 服务器设置，内置 `api.themoviedb.org` 与 `api.tmdb.org`，并支持输入自定义 HTTP/HTTPS 地址。
- 代理：系统设置新增通用代理服务器，自动识别 `http://` 与 `socks://` 地址，支持无认证、用户名密码认证和仅密码认证；保存后默认隐藏认证信息，可通过已登录的按需请求显示完整连接串；当前仅用于后端 TMDb API 请求。
- 代理测试：新增固定使用 `http://www.google.com/generate_204` 的延迟测试，限制超时与重定向，返回 HTTP 状态和延迟，并对 API Key、Bearer Token 与代理凭据进行错误脱敏。
- 兼容：自动读取旧 `tmdb_proxy` 配置，保留未修改的已保存密码；修复旧接口把字符串 `false` 误判为启用的问题。
- 依赖：后端增加 `PySocks`，前端图标依赖由 Element Plus Icons 切换为 `@lucide/vue`。
- 文档：更新功能说明、代理格式、源码目录、接口列表和版本号。

验证说明

- 已使用源码模式完成 Python 语法、后端单元测试、代理 HTTP/SOCKS5 认证回归、前端单元测试、ESLint、Vue dev server、桌面与移动端浏览器回归、语言键和 Lucide 导入检查。
- 未执行前端生产构建、Docker 构建、PyInstaller、StaticX、Android APK 或发布包构建；这些产物需由正式发布流程验证。
