# v0.2.0（2026-07-02）

变更概述

- 优化：媒体名字刮削手动执行历史任务时，会从历史任务 request plans 中恢复根目录重命名线索，避免中止或失败任务丢失 rootRenames 后再次执行时选到不存在的目标路径。
- 优化：OpenList 批量移动接口超时后，会刷新源目录和目标目录做二次核验；实际已经移动完成的文件会补成功日志，未完成的文件再按单文件重试。
- 优化：电视剧季目录识别支持 `S00`、`S01` 等目录名；`S00 -> Season 0` 这类同父级季目录调整会优先重命名目录，退回文件移动时会清理空季目录链。
- 优化：过滤嵌套根目录重命名项，避免 `S00` 子目录被误记录为独立根目录重命名任务并产生假失败。
- 新增：媒体名字刮削任务结果接入通知配置，任务成功、部分失败、失败或中止后会发送任务名称、路径、统计数量、耗时和失败原因。
- 调整：媒体刮削默认电影命名模板更新为保留片源、版本、分辨率、HDR、视频/音频编码、自定义标签和制作组的格式；电视剧模板保持同一套参数风格。
- 文档：更新 README 媒体名字刮削说明，并在 AGENTS.md 中明确版本号递增规则：每段数字最大为 9，`v0.1.9` 的下一版为 `v0.2.0`。

注意事项

- 已经由旧逻辑生成的空 `S00` 目录，需要再次执行对应媒体刮削任务才会触发空季目录清理。
- 本版本只更新源码和文档；发布 Docker 或静态前端仍需按发布流程重新构建前端产物。
