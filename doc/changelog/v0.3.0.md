# v0.3.0（2026-07-30）

变更概述

- 升级：同步 TaoSync `v0.4.0` 的新增能力，并继续保留 OpenList 引擎、Webhook、全局排除项和媒体名字刮削等现有功能与数据契约。
- 前端：迁移到 Vue 3、Vite、Element Plus 与 Pinia，增加亮色/暗色主题、中英文切换和移动端页面；移除已停用的 Vue 2 `frontend/` 源码。
- 国际化：增加前后端中英文语言资源、请求语言上下文和回退逻辑，后端响应与任务通知可跟随所选语言。
- 作业：增加最小/最大文件大小过滤，等于边界的文件仍参与同步；APScheduler 错过执行时间的宽限期调整为 15 分钟。
- 配置：初始管理员密码支持 `OPENLISTSYNC_PASSWORD`，并兼容 `TAO_PASSWORD`、`TAO_PASSWD`；启动日志不再输出配置密码。
- 通知：增加企业微信应用消息和 Lark 群机器人通知，并补充参数校验及网络错误脱敏。
- 平台：增加 Android 客户端入口、图标和 Buildozer 配置，并扩展 Linux StaticX、多架构及发布工作流。
- 数据库：结构版本升级到 `260729`，兼容 `v0.2.1` 数据，保留 OpenList 引擎、同步作业、全局排除项、通知配置及媒体刮削配置和任务记录。
- 媒体刮削：支持直接选择单个媒体文件并切换智能识别、电影或电视剧；修复电影目录重复嵌套、历史任务重跑路径变化、OpenList 移动超时后二次核验及 HDR10P 标签识别。
- Webhook：创建作业时支持按 `WEBHOOK_OPENLIST_NAME` 选择引擎，刷新时覆盖电视剧所有季目录，并对访问日志中的 `apikey` 等敏感参数脱敏。
- 清理：移除误纳入版本控制的 `.venv/`、旧 Vue 2 前端和无引用重复资源，目录树改为当前 Vue 3 源码结构。

升级说明

- 支持从 `v0.2.1` 直接升级到 `v0.3.0`。升级前请结束正在运行的同步和重命名任务，并备份整个 `data/` 目录。
- 源码部署需要重新安装后端与 `web/` 前端依赖；Docker 或发布包部署请使用与 `v0.3.0` 对应的产物。升级后若仍显示旧界面，请强制刷新浏览器缓存。
- 数据库完成迁移后不建议直接使用旧版本继续写入；如需回退，请同时恢复升级前备份的 `data/` 目录。

验证说明

- 已使用源码模式完成 Python 语法、数据库迁移、后端接口与媒体刮削测试，以及 Vue dev server、前端单元测试、ESLint、依赖树和语言键检查。
- 未执行前端生产构建、Docker 构建、PyInstaller、StaticX、Android APK 或发布包构建；这些产物需由正式发布流程验证。
